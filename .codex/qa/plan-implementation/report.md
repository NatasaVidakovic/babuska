# Café Babuska implementation QA report

## Executive summary

The approved centered bilingual/Supabase-media implementation was reviewed across the public site, administrator workflows, database policies, Storage, and target responsive breakpoints. Three implementation defects were found and fixed during this review. No known critical, high, medium, or low issue remains open in the tested scope.

## Fixed findings

1. **Admin labels were not associated with their inputs** — Accessibility/Medium. The visual labels now use stable generated IDs and `htmlFor`, and browser label-based interaction succeeds.
2. **Legacy demo row caused 31 English menu items** — Content/Medium. The seed now removes only the precisely identified incomplete legacy duplicate and consistently produces 30 bilingual items.
3. **Five legacy gallery images still used external hosts** — Security/Medium. The idempotent media migration moved them into Supabase Storage; all published hero/menu/gallery media now has an allowed Storage folder path.

## Verified scope

- Serbian Cyrillic default and complete English switching on public/admin UI.
- Homepage image remains unchanged when language changes.
- Five dynamic category filters and 30 ordered menu items.
- Menu book follows category order.
- Admin content, categories, menu items, gallery, hero, footer, contact, and social-link flows.
- Anonymous write denial and administrator-only writes.
- Public reads of published content and Storage media.
- Responsive public layout at 360×640, 390×844, 768×700, 1024×600, 1366×768, and 1440×900.
- Mobile admin login layout at 360×640.
- No browser console errors during public and authenticated admin inspection.
